# 🧰 Antes de empezar

- Todos los comandos de Git empiezan por `git`.
- Git necesita saber quién eres (configuración global).
- Git trabaja **dentro de repositorios**.
- Muchos comandos solo funcionan si **estás dentro de un repositorio**.

---

# 📦 Crear un repositorio local

Primero creamos o abrimos una carpeta donde queremos trabajar. Para convertir esa carpeta en un repositorio Git, ejecutamos:

```bash
git init .
```

## 📌 Inicializar repositorio en otra ruta

En `git init .` el punto representa el directorio actual. Puedes inicializar un repositorio sustituyendo el "." por la ruta del directorio a inicializar:

```bash
git init /ruta/a/proyecto
```

## 📝 ¿Qué hace realmente este comando?

`git init` crea una carpeta oculta llamada **`.git`**. 

Dentro de esa carpeta Git almacena:
- el historial
- los commits
- las ramas
- las configuraciones del repositorio
- los objetos internos (blobs, trees, etc.)

> [!CAUTION]
> **Nunca borres la carpeta `.git`** a menos que quieras eliminar TODO el historial del repositorio.

---

# 🗂️ Verificando que estás en un repositorio Git

Puedes comprobar que Git reconoce tu carpeta como un repositorio:

```bash
git status
```

Si todo va bien, verás un mensaje como:

```
On branch main
No commits yet
nothing to commit (create/copy files and use "git add" to track)
```

---

# 🗃️ Primera estructura del repositorio

Cuando Git inicia un repositorio, crea la rama por defecto:

- `main` (en versiones recientes)
- `master` (en repositorios antiguos)

Esto todavía **no contiene commits** hasta que añadas archivos y hagas tu primera confirmación.

---

# 🧹 Eliminar un repositorio Git

Si quieres dejar de usar Git en esa carpeta:

```
rm -rf .git
```

> [!Warning]
> Esto borra el repositorio, ramas e historial.  Los archivos del proyecto NO se borran.
