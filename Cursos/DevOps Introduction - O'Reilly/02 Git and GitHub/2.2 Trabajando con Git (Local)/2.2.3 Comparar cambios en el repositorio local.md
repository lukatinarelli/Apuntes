# 📝 1. Comparar _Working Directory_ vs _Staging Area_

(Archivos modificados pero NO añadidos al staging)

Este comando muestra los cambios que **aún no están preparados** para commit.

```bash
git diff
```

Sirve para ver:
- Qué se modificó en un archivo antes de hacer `git add`
- Qué líneas se añadieron o eliminaron
- Qué cambios aún NO están en el staging area

---

# 📦 2. Comparar _Staging Area_ vs _Repositorio local_

(Cambios añadidos con `git add` pero aún NO confirmados)

```bash
git diff --staged
```

o

```bash
git diff --cached
```

Ambos comandos hacen lo mismo.

Sirve para:
- Revisar qué cambios se van a incluir en el próximo `commit`
- Confirmar que lo que has añadido con `git add` es lo que realmente quieres commitear

---

# 🏛️ 3. Comparar commits, archivos específicos o rangos

Git también permite comparar versiones entre sí.

## Comparar dos commits:

```bash
git diff <commit1> <commit2>
```

## Comparar un archivo en el commit actual vs la versión anterior:

```bash
git diff HEAD~1 archivo.txt
```

## Comparar el Working Directory con un commit específico:

```bash
git diff <commit_id> archivo.txt
```

# 🔍 Comandos útiles relacionados

|Acción|Comando|
|---|---|
|Ver qué archivos cambiaron|`git status`|
|Ver historial de commits|`git log`|
|Ver el último commit con formato resumido|`git log --oneline`|
