# 🌐 GitHub: ¿Por qué usar un repositorio remoto?

Hasta ahora hemos trabajado únicamente con Git en **local**. Esto está bien para practicar o trabajar solo, pero **no sirve en un entorno real**, donde:

- 👥 varias personas necesitan colaborar
- 💻 quieres acceder al código desde diferentes dispositivos
- 🔒 necesitas una copia segura en la nube
- 🚀 debes integrar tu trabajo con pipelines CI/CD

Para solucionar esto, usamos repositorios **remotos**, que funcionan como un punto central donde cada desarrollador puede:

- ⬆️ subir cambios (push)
- ⬇️ descargar cambios (pull)
- 🔄 sincronizarse con el resto del equipo

Uno de los servicios más utilizados para alojar repositorios remotos es **GitHub**, que usaremos en este curso.

---

# 👤 Crear una cuenta personal en GitHub

1. Visita **[https://github.com/](https://github.com/)**
2. Haz clic en **Sign up** (Registrarse).
3. Opcional: usa **Sign in with Google** para registrarte con tu cuenta de Google.
4. Completa los pasos de registro: correo, contraseña, verificación, etc.
5. Confirma tu correo electrónico mediante el mensaje que recibirás.

> 💡 Consejo: usa una cuenta personal (no corporativa) para conservar tus repositorios siempre.

---

# 📁 Crear tu primer repositorio en GitHub

1. En la esquina superior derecha, haz clic en **`+`** → **New repository**. 
<img src="../../imágenes/create_repo_github.webp" width="400">

2. En **Repository name**, escribe por ejemplo:  
    `hello-world`
3. En **Description**, añade un texto breve:  
    “Repositorio de práctica para aprender Git y GitHub”.
4. Selecciona la visibilidad:
    - 🌍 **Public** → cualquiera puede verlo
    - 🔐 **Private** → solo tú (y quien invites)
5. Marca **Add a README file** para generar el README inicial.
6. Haz clic en **Create repository** 🎉

Tu repositorio queda creado en GitHub y ya está listo para clonarlo o conectarlo con tu repositorio local.
