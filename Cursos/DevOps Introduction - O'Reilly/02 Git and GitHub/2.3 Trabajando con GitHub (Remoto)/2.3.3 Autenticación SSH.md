# 🔐 Autenticación SSH

La autenticación SSH te permite conectarte a GitHub **sin escribir tu usuario y contraseña o token cada vez que haces `git push` o `git pull`**.  
Es segura, práctica y la opción más usada por profesionales.

---

# 🧰 ¿Por qué usar SSH?

- No tienes que escribir contraseñas.
- Funciona con claves criptográficas únicas.
- Es más segura que HTTPS con usuario/contraseña.
- Ideal para trabajo continuo con GitHub.

---

# 🗝️ Generar una clave SSH

1. Abrir una **terminal**.
2. Ejecutar el siguiente comando (sustituye el correo por el que usas en GitHub):

```bash
ssh-keygen -t ed25519 -C "tu-email@ejemplo.com"
```

> Si tu sistema no soporta ED25519:

```bash
ssh-keygen -t rsa -b 4096 -C "tu-email@ejemplo.com"
```

3. Cuando te pregunte:
    - **Dónde guardar la clave**, presiona **Enter** para aceptar la ubicación por defecto:  
        `/home/usuario/.ssh/id_ed25519` o similar.
    - **Passphrase** → opcional pero recomendado (añade seguridad extra).

Esto generará dos archivos:

- **id_ed25519** → tu _clave privada_ (NO se comparte nunca)
- **id_ed25519.pub** → tu _clave pública_ (SÍ se comparte con GitHub)

---

# 📤 Añadir la clave SSH al agente (ssh-agent)

1. Iniciar el agente:

```bash
eval "$(ssh-agent -s)"
```

2. Añadir tu clave privada:

```bash
ssh-add ~/.ssh/id_ed25519
```

---

# 📎 Añadir tu clave pública en GitHub

1. Copiar tu clave pública:

```bash
cat ~/.ssh/id_ed25519.pub
```

Copia todo el contenido (empieza con `ssh-ed25519` o `ssh-rsa`).

2. Ir a **GitHub → Settings** (Configuración).
3. En la barra lateral, abrir **SSH and GPG keys**.
4. Hacer clic en **New SSH key**.
5. Poner un nombre (ej. _Mi portátil_, _PC trabajo_).
6. Pegar la clave pública.
7. Guardar con **Add SSH key**.

---

# 🔍 Probar la conexión

Ejecuta:

```bash
ssh -T git@github.com
```

Si todo está bien, verás algo como:

```
Hi TU-USUARIO! You've successfully authenticated, but GitHub does not provide shell access.
```

---

# 🚀 Usar SSH para clonar repositorios

A partir de ahora, en GitHub selecciona la opción **SSH** al clonar repos:

```bash
git clone git@github.com:TU-USUARIO/TU-REPO.git
```
