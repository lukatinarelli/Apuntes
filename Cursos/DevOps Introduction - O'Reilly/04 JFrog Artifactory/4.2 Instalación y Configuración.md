# 🛠️ Instalación y Configuración de JFrog Artifactory (OSS)

En este laboratorio instalaremos **JFrog Artifactory Open Source (OSS)** en un servidor Linux.

Artifactory es una aplicación Java pesada, por lo que los requisitos de hardware son más estrictos que para un servidor web simple.

> [!NOTE]
> Existe versión Pro/Enterprise de pago con trial de 30 días, que añade features avanzadas (replicación, Xray, HA, etc.). Para aprender y labs de infra, OSS es suficiente.

# 📋 1. Requisitos de Infraestructura (AWS EC2)

Al lanzar la instancia en AWS, hay dos puntos críticos que difieren de lo que hemos hecho hasta ahora:

1. **Tipo de Instancia (RAM)**
    - Artifactory requiere **mínimo 2GB de RAM**.
    - La capa gratuita (`t2.micro` o `t3.micro` con 1GB) **NO SIRVE**. El proceso Java fallará con error de asignación de memoria (`fork cannot allocate memory`).
    - **Recomendado:** `t3.medium` (2 vCPU, 4GB RAM).
    - **Mínimo absoluto:** `t3.small` (funciona, pero muy justo).
2. **Security Group (Puertos)**
    - Artifactory corre por defecto en **8081** (UI + repositorios) y **8082** (Router interno).
    - Añadir reglas de entrada TCP para **8081** desde tu IP o Anywhere (0.0.0.0/0).

# 📥 2. Descarga e Instalación Manual (Debian/Ubuntu)

Si usas una distro basada en Debian:

```Bash
# 1. Ir a un directorio temporal
cd /tmp

# 2. Descargar Artifactory OSS (revisar última versión en web oficial)
wget https://releases.jfrog.io/artifactory/bintray-artifactory/org/artifactory/oss/jfrog-artifactory-oss-[VERSION].deb

# 3. Instalar
sudo dpkg -i jfrog-artifactory-oss-*.deb
```

---

# 🚀 3. Iniciar el Servicio


```Bash
# Iniciar Artifactory como servicio
sudo systemctl start artifactory

# Verificar estado
sudo systemctl status artifactory
```

> [!WARNING]
> **Tiempo de Arranque:** Artifactory tarda 1-2 minutos en iniciar completamente el servicio de Java. Ten paciencia si la web no carga al instante.

---

# ⚙️ 4. Configuración Inicial (Wizard)

Abrir navegador en: `http://<IP-PUBLICA-EC2>:8081`

1. **Pantalla de Bienvenida:** "Welcome to Artifactory".
2. **Credenciales por defecto:**
    - User: `admin`
    - Password: `password`
3. **Licencia:**
    - **OSS:** No requiere licencia.
    - **Pro/Enterprise:** Requiere trial key.
4. **Cambio de contraseña:** Obligatorio (ej. `Admin@123`).
5. **Selección de Paquetes:**
    - Selecciona **Maven** (para este curso).
    - También soporta Docker, npm, NuGet, etc.
6. **Creación de Repositorios Automática:**
    - `libs-release-local`
    - `libs-snapshot-local`
    - `jcenter` (Remoto)

> [!TIP]
> Artifactory actúa como single source of truth. Evita que tus builds dependan de si Maven Central está caído o si tu conexión a internet falla.

---

# ☸️ Contexto DevOps: IP Elástica

- Si apagas la instancia EC2 (`Stop/Start`), la IP pública cambia, rompiendo la configuración de Jenkins y desarrolladores.
- **Solución:** Asignar una **Elastic IP** a la instancia.
- En entornos reales se usaría además **DNS (Route53)** apuntando a un Load Balancer.

# 📚 Bonus / Tips

- **Logs:** `/opt/jfrog/artifactory/var/log`
- **Configuración:** `/opt/jfrog/artifactory/var/etc/system.yaml`
- **Gestión Servicio:** `sudo systemctl restart artifactory`
- **Datos (Backups):** `/opt/jfrog/artifactory/var/data`
