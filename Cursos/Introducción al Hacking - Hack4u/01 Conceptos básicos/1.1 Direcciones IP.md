# 🧭 ¿Qué es una dirección IP?

Una **dirección IP** (Internet Protocol Address) es un identificador numérico asignado a una **interfaz de red** de un dispositivo.

Su función es permitir que los equipos:

- **se identifiquen entre sí**,
- **puedan intercambiar información**,
- **sepan a dónde enviar los paquetes**,
- y **reciban respuestas correctamente**.

La IP funciona de manera **jerárquica**, igual que una dirección postal:

- Existe una "parte de red", que te dice en qué barrio estás.
- Existe una "parte de host", que identifica tu casa dentro del barrio.

> [!NOTE]
> En redes, toda comunicación depende de dos cosas: **quién eres** (tu IP) y **cómo llego a ti** (tu ruta).

# 🖥️ 2. Cómo ver tu IP en tu sistema

Cuando ejecutas un comando para ver tus interfaces, cada una puede tener **su propia dirección IP**.  
Esto incluye:

- Interfaces físicas (Wi-Fi, Ethernet)
- Interfaces virtuales (máquinas virtuales, Docker, VPNs)
- La interfaz local (`lo` / loopback)

## 🔹 En Windows

```bash
ipconfig
```

## 🔹 En Linux (modo clásico)

```bash
ifconfig
```

## 🔹 En Linux (modo recomendado)

```bash
ip a
```

> [!TIP]
> Estos comandos muestran **todas** tus interfaces: físicas, virtuales, activas, en pausa, con IPv4, IPv6, etc.

## 🔹 Ver solo la IP de forma rápida

```bash
hostname -I
```

Ideal si solo quieres saber tu IP en la red local sin leer 50 líneas de output.

# 🌍 3. Direcciones IPv4

La **IPv4** es el formato original de direccionamiento de Internet.  
Fue creada en 1981 y todavía es la más común.

Es fácil de leer: cuatro números separados por puntos:

```
A.B.C.D
```

Ejemplo:

```
192.168.1.2
```

## 🧩 3.1 Estructura interna de IPv4

Cada número (octeto) representa **8 bits**, así:

```
4 octetos × 8 bits = 32 bits
```

Internamente, el ordenador no guarda “192”, sino su valor en **binario**, ya que así trabaja la CPU.

Ejemplo (resumido):

- 192 → `11000000`
- 168 → `10101000`
- 1 → `00000001`
- 2 → `00000010`

Por tanto:

```
192.168.1.2  →  11000000.10101000.00000001.00000010
```

## 💡 3.2 Pequeñísima introducción al binario (solo lo esencial)

El sistema binario utiliza solo dos dígitos:

```
0 y 1
```

Cada posición tiene un valor asociado:

```
128 | 64 | 32 | 16 | 8 | 4 | 2 | 1
```

Para obtener un número, sumas solo las posiciones donde aparece un 1.

Ejemplo rápido:  
`11000000` = 128 + 64 = 192 ✔️

Esto es suficiente para entender de dónde salen las IPv4 en binario.

## 📦 3.3 Capacidad total de direcciones IPv4

Como IPv4 tiene 32 bits:

```
2^32 = 4.294.967.296 direcciones posibles
```

Unos **4.3 mil millones**.

Hace años esto parecía muchísimo…  
Pero hoy en día tenemos:

- Ordenadores
- Teléfonos
- Televisores
- Cámaras
- Dispositivos IoT
- Contenedores
- Máquinas virtuales
- Vehículos
- Sensores…

→ IPv4 simplemente **no da para todos**.  
Y por eso nació IPv6.

# 🌀 4. Direcciones IPv6

IPv6 es la evolución natural del direccionamiento.  
Fue diseñada para **no volver a tener problemas de espacio**, pero también introduce:

- Mejor eficiencia en el enrutamiento
- Mayor seguridad integrada
- Eliminación de procesos como NAT en muchos casos
- Autoconfiguración automática

## 🧩 4.1 Estructura interna de IPv6

Una IPv6 tiene **128 bits**, lo que la hace gigantescamente más grande.

Se representa así:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

Cada bloque está en **hexadecimal**, porque escribir 128 bits en binario sería inviable.

## ✂️ 4.2 Reglas de simplificación

IPv6 permite abreviaciones:

1. **Quitar ceros a la izquierda**  
    `0000` → `0`  
    `0370` → `370`
2. **Colapsar secuencias largas de ceros**  
    Se reemplazan por `::` **una sola vez por dirección**.

Ejemplo real:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
→ 2001:db8:85a3::8a2e:370:7334
```

## 🌌 4.3 Capacidad total

Este número es tan grande que cuesta imaginarlo:

```
2^128 ≈ 340.282.366.920.938.463.463.374.607.431.768.211.456
```

O de forma más digerible:

> [!NOTE]
> Puedes asignar **miles de direcciones IPv6 a cada milímetro cuadrado de la Tierra**, y aún así no se agotarían.

IPv6 es el futuro… aunque **la transición es lenta**, y todavía convivimos con IPv4.

# 🧩 5. Tipos de direcciones IP

Aunque lo veremos más adelante, conviene conocer la idea general:

## 🔹 IPv4

- Públicas
- Privadas
- Loopback
- Reservadas
- Broadcast
- Multicast

## 🔹 IPv6

- Global Unicast
- Unique Local
- Link‑Local
- Loopback
- Multicast

> [!TIP]
> Entender “qué tipo de IP estás viendo” te permite saber si una máquina es accesible, si está en tu red, o si pertenece a otra red totalmente diferente.

# 🧠 6. ¿Por qué es esencial dominar las direcciones IP en hacking?

En ciberseguridad ofensiva, manejar IPs es tan básico como manejar rutas o puertos.  
Saber interpretarlas te ayuda a:

- Identificar qué redes estás escaneando
- Distinguir direcciones públicas de privadas
- Reconocer interfaces virtuales (Docker, VMware, VPNs…)
- Comprender el alcance de tus pruebas
- Evitar atacar accidentalmente redes ajenas
- Entender configuraciones de VPN, túneles, proxys, NAT
- Configurar máquinas vulnerables en redes aisladas

> [!IMPORTANT]
> Un pentester que domina las IP es mucho más rápido detectando vectores de ataque.

---

# 📝 Resumen final

- Una **dirección IP** identifica a una interfaz en una red.
- En Windows/Linux puedes verlas con `ipconfig`, `ifconfig`, `ip a`.
- IPv4 usa **32 bits**, 4 números, y tiene ~4.3 mil millones de direcciones.
- IPv6 usa **128 bits**, 8 bloques hexadecimales, y es prácticamente infinito.
- Saber leer y entender IPs es fundamental en hacking y administración de redes.
