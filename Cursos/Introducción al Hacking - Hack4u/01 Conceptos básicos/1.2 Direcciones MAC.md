# 🧭 ¿Qué es una dirección MAC?

En redes de computadoras, una **dirección MAC** (Media Access Control) es un **identificador único de 48 bits** asignado a la tarjeta o dispositivo de red.  

También se conoce como **dirección física**, ya que identifica al hardware **de manera única dentro de una red local**.

> [!NOTE]  
> Aunque se dice que es “única”, la dirección MAC puede modificarse mediante herramientas específicas como `macchanger` o configuraciones de sistema.

---

# 🧩 2. Estructura de una dirección MAC

Una MAC típica tiene el formato:

```
a0:80:69:62:8c:57
```

Se puede dividir en **dos partes principales**:

1. **OUI (Organizationally Unique Identifier)** → Los **3 primeros octetos** (`a0:80:69`) identifican al **fabricante** de la tarjeta de red.
2. **NIC (Network Interface Controller)** → Los **3 últimos octetos** (`62:8c:57`) identifican de manera única la tarjeta dentro del fabricante.

> [!TIP]  
> Conocer el OUI te permite identificar el fabricante de la tarjeta de red. Esto puede ser útil para análisis de red o detección de dispositivos específicos en entornos de pentesting.

## 🔹 OUI en detalle

- Cada fabricante registra su OUI en una base de datos oficial.
- Esto permite que cualquier dirección MAC pueda asociarse con un fabricante reconocido.
- Herramientas como `oui.txt` o servicios online permiten **consultar rápidamente el fabricante** a partir de los 3 primeros octetos.

---

# 🖥️ 3. Cómo ver la dirección MAC

## 🔹 En Windows

```bash
ipconfig /all
```

## 🔹 En Linux (modo clásico)

```bash
ifconfig
```

## 🔹 En Linux (modo recomendado)

```bash
ip a
```

> [!TIP]  
> Estos comandos mostrarán **todas las interfaces de red** con su dirección MAC, dirección IPv4, IPv6 y estado de la interfaz.

---

## 🔄 4. Cambiar la dirección MAC

Modificar la MAC puede ser útil para pruebas de seguridad o anonimato.  
Ejemplo rápido usando **Linux**:

```bash
# Instalar macchanger si no lo tienes
sudo apt install macchanger

# Cambiar la MAC de la interfaz wlan0 de forma aleatoria
sudo macchanger -r wlan0
```

> [!CAUTION]  
> Cambiar la MAC de interfaces activas puede causar pérdida de conectividad momentánea. Úsalo solo en **entornos controlados**.

> [!NOTE]  
> Esta técnica se estudia más a fondo en el módulo de **hacking Wi-Fi**, donde el spoofing de MAC es relevante para pruebas de penetración en redes inalámbricas.

---

# 📝 5. Resumen final

- La **MAC** es la dirección física de una tarjeta de red, única por diseño.
- Se compone de **OUI + NIC** (fabricante + dispositivo).
- Se puede consultar fácilmente con comandos de sistema (`ipconfig`, `ifconfig`, `ip a`).
- Es posible **modificarla** para pruebas o anonimato usando herramientas como `macchanger`.
- Conocer la MAC y su OUI ayuda a **identificar dispositivos y fabricantes** en redes locales.
