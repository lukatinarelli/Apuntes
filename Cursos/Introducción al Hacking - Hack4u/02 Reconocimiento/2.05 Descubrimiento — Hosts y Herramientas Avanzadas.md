# 📚 Explicación teórica: Protocolos de Descubrimiento

El Descubrimiento de Hosts (Host Discovery) es la primera parte del reconocimiento. Consiste en identificar qué direcciones IP dentro de un rango determinado corresponden a equipos activos (encendidos) en la red.

Las dos técnicas principales se basan en:

1.  **ICMP (Internet Control Message Protocol):** El clásico comando `ping`. Útil para redes remotas, pero a menudo bloqueado por firewalls.
2.  **ARP (Address Resolution Protocol):** Utilizado para mapear direcciones IP a direcciones MAC en la red local (LAN). **Es el método más fiable en la red local** ya que ARP es fundamental para el funcionamiento de la red y no se suele filtrar.

## 💡 Obtención de Rango

Para saber qué escanear, primero se identifica la IP local y la máscara de subred.

1.  **Obtener IP y Máscara:** Usando comandos como `ip a` o `ifconfig`.

    ```bash
    ip a 
    # Muestra: inet 192.168.111.43/24
    ```

2.  **Deducción:** Si la IP es `192.168.111.43` y la máscara es `/24` (o `255.255.255.0`), la red a escanear es la **`192.168.111.0/24`**.

# 🛠️ Herramientas de Descubrimiento

## 1. Nmap (Ping Sweep) — `-sn`

Nmap tiene un modo específico para descubrimiento de hosts sin escanear puertos, conocido como **Ping Sweep** o **Host Discovery**.

```bash
nmap -sn 192.168.111.0/24 
````

- **`–sn` (Skip Port Scan):** Desactiva el escaneo de puertos. Nmap intenta determinar la actividad mediante ARP (en LAN), ICMP, y sondeos TCP/UDP a puertos comunes.

## 2. ARP-Scan (El más fiable en LAN)

`arp-scan` utiliza exclusivamente el protocolo ARP para descubrir hosts, lo que lo hace **extremadamente rápido y preciso** dentro de la red local.

```Bash
# -I: Especifica la interfaz de red (ej. eth0, wlan0)
# --localnet: Escanea todo el rango local detectado automáticamente
arp-scan -I wlp0s20f3 --localnet 
```

- **`--ignoredups`**: Opción importante para limpiar la salida y no mostrar entradas duplicadas causadas por máquinas virtuales o configuraciones especiales.

## 3. Netdiscover (Menos recomendado)

`netdiscover` realiza un barrido de red, pero a menudo utiliza máscaras más amplias de lo necesario (ej. `/16`), lo que lo hace más lento y ruidoso si la máscara real es `/24`. Es una opción viable solo si `arp-scan` no está disponible.

```Bash
# Netdiscover solo necesita la interfaz
netdiscover -i wlp0s20f3
```

# 📝 Procedimiento Manual

Es posible crear nuestro propio escáner de ping de forma manual para evitar cualquier firma de herramienta.

## 💻 Comando Base de Verificación

Para verificar si un solo host está activo de forma rápida y silenciosa:

```Bash
timeout 1 bash -c "ping -c 1 192.168.111.1" &>/dev/null && echo "[+] Host 192.168.111.1 activo"
```

- **ping -c 1:** un solo paquete
- **timeout 1:** Limita el tiempo de ejecución a 1 segundo si el host está caído
- **&>/dev/null:** Silencia toda la salida (stdout y stderr)
- **&& echo...:** Solo ejecuta el 'echo' si el comando anterior fue exitoso (código de salida 0)

## Script de Descubrimiento Paralelo

El procedimiento manual se optimiza en un script Bash (análogo al `portScan.sh` de la nota 2.4) usando un bucle `for` y la ejecución en segundo plano (`&`) para paralelizar el escaneo.

> [!TIP]
> **Paralelismo (&):** Es vital usar el símbolo & al final del comando dentro del bucle. Esto ejecuta cada ping simultáneamente. Si no se usa, el script tardaría 254 segundos (un segundo por host) en lugar de unos pocos segundos en total.

🔗 **Script de Escaneo Manual:** Puedes adaptar el script [portScan.sh](../Recursos/Scripts/portScan.sh) de la nota 2.4 para reemplazar la función `checkport` con la lógica de `ping`/`timeout`.

# 📈 Masscan: Escaneo de Alto Rendimiento

Masscan es una herramienta que se sitúa en el extremo opuesto del sigilo: está diseñado para escanear **toda la Internet** en minutos, o redes corporativas masivas en segundos.

- **Velocidad:** Nmap escanea miles de puertos/minuto. Masscan escanea **millones** de paquetes/segundo.
- **Funcionamiento:** Masscan utiliza una pila TCP/IP propia y envía paquetes de forma asíncrona y sin estado.

## 💻 Comandos Comunes

```Bash
# Escanea puertos comunes en un amplio rango (/16) a alta velocidad
masscan 192.168.0.0/16 -p21,22,80,443,8080 --rate=10000
```

- **`--rate`:** Es el parámetro de control de velocidad.
    - `--rate=1000000`: Para escaneos masivos de Internet.
    - `--rate=1000`: Para escaneos más lentos y fiables en LAN (reduce la pérdida de paquetes).

> [!WARNING]
> A diferencia de Nmap, Masscan está diseñado para velocidad bruta. Al aumentar `--rate`, la probabilidad de perder respuestas (paquetes) o de activar sistemas IDS aumenta drásticamente.

# 🔎 Tip de Alcance

> [!TIP]
> **Exploración Amplia (/16 vs. /24):**
> 
> Aunque estés conectado a una red local que parece ser una `/24` (ej. `192.168.111.0/24`), siempre es una buena práctica de reconocimiento escanear rangos más amplios, como una `/16` (ej. `192.168.0.0/16`).
> 
> **Razón:** Algunas redes corporativas utilizan subredes no contiguas para segmentación (VLANs, diferentes departamentos, VPNs). Al escanear el rango `192.168.0.0/16`, podrías descubrir hosts en subredes no obvias (ej. `192.168.87.16`) a las que tienes acceso de forma indirecta o que son accesibles debido a reglas de ruteo laxas.
