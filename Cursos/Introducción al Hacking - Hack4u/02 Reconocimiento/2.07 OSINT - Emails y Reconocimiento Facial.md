# 📚 Explicación teórica: OSINT en Phishing

El **OSINT (Open Source Intelligence)** es la recolección y análisis de información disponible públicamente. En el contexto del *hacking*, es la fase inicial de reconocimiento pasivo, esencial para diseñar ataques de **Phishing** o de Ingeniería Social altamente efectivos.

El ataque más común hoy en día es el **Phishing**, donde un atacante se hace pasar por una entidad de confianza (CEO, soporte técnico, banco) para obtener credenciales. Para que un Phishing sea exitoso, necesita:

1.  **Objetivo Específico:** Direcciones de correo electrónico válidas.
2.  **Credibilidad:** Conocimiento de la víctima (foto, cargo, redes sociales) para imitar su entorno.

---

# 🛠️ Herramientas para Recolección de Correos

La obtención de direcciones de correo electrónico corporativas es el primer paso en la creación de una lista de objetivos para Phishing.

## 1. 📬 Hunter.io

Hunter es la herramienta más sencilla para encontrar direcciones de correo electrónico asociadas a un dominio específico.

* **Uso:** Introduce el dominio (ej. `tinder.com`) y Hunter buscará correos, nombres y la fuente donde encontró la dirección.
* **Limitación:** Requiere registro y tiene un límite de búsquedas gratuitas diarias.

> [!NOTE]
> Hunter a menudo devuelve el patrón de correo (ej. `{nombre}.{apellido}@empresa.com`), lo cual es vital para deducir otros correos.

🔗 **Web Oficial:** https://hunter.io/

## 2. 🧠 Intelligence X

Se describe como un motor de búsqueda avanzado, *más potente que Google o la NSA* en la indexación de datos sensibles. Es excelente para buscar información relacionada con:

- Direcciones de correo electrónico específicas.
- Nombres de usuario.
- Datos filtrados en _data leaks_.

🔗 **Web Oficial:** https://intelx.io/

## 3. 📞 Phonebook.cz

Un motor de búsqueda de OSINT muy valioso y gratuito, que indexa dominios, correos electrónicos, URLs y otros datos de contacto, proporcionando una vista amplia de las entidades en la red.

🔗 **Web Oficial:** https://phonebook.cz/

# 📸 Reconocimiento Facial y Ingeniería Social

Una vez que se tiene un correo asociado a un nombre (gracias a Hunter, a menudo con un enlace a LinkedIn), se puede obtener una foto del objetivo. Esta foto se utiliza para pivotar hacia un reconocimiento de imágenes profundo.

## PimEyes — Reconocimiento Facial

PimEyes utiliza tecnología de **reconocimiento facial** para encontrar copias de una imagen dada en toda la Internet, incluyendo redes sociales, blogs, y sitios web.

- **Mecanismo:** Analiza los **patrones faciales** de la imagen de entrada y los compara con su vasta base de datos.
- **Potencial de Auditoría:** Si se tiene la foto de un CEO o un empleado clave, PimEyes puede revelar:
    - Perfiles secundarios y desconocidos.
    - Sitios web personales.        
    - Información que puede usarse para imitar la personalidad o el comportamiento del objetivo en un ataque de Ingeniería Social.        

> [!WARNING]
> La versión gratuita de PimEyes permite ver los dominios principales donde aparece la foto, pero se requiere una suscripción para ver la URL exacta de la imagen. Invertir en el plan mensual puede ser crucial para una auditoría de Ingeniería Social profunda.

🔗 **Web Oficial:** https://pimeyes.com/en

# 📝 Notas importantes

> [!NOTE]
> **Phishing Altamente Dirigido (Spear Phishing):** La combinación de correos válidos y conocimiento personal (obtenido por PimEyes) permite crear correos de Phishing tan personalizados que la probabilidad de éxito es muy alta.
