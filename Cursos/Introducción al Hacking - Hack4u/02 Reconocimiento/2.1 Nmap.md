# Introducción

Cuando un atacante quiere comprometer un sistema, una de las primeras cosas que debe hacer es **descubrir los puertos abiertos** y los servicios que se ejecutan en ellos. Cada puerto expone un servicio: SSH en el 22, HTTP en el 80, MySQL en el 3306…

Escanear puertos te permite saber:

- **Qué servicios están disponibles**
- **Qué versiones de software corren**
- **Qué podría ser vulnerable**
- **Qué superficie de ataque ofrece el objetivo**

Por eso esta fase del reconocimiento es esencial.

Para esta tarea, una de las herramientas más potentes es **Nmap**, un escáner de puertos y servicios extremadamente completo.

# Instalación de Nmap

## Linux

### CentOS

#### CentOS 6/7:

```bash
sudo yum install nmap
```

#### CentOS 8:

```bash
sudo dnf install nmap -y
```

### Debian/Ubuntu:

```bash
sudo apt update
sudo apt install nmap -y
```

## Windows

Nmap también funciona en Windows.

### 1. Descargar

Ve a la web oficial: **[https://nmap.org/download.html](https://nmap.org/download.html)**  
Descarga el instalador para Windows (incluye Zenmap si quieres GUI).

### 2. Instalar

Ejecuta el `.exe` y deja todas las opciones marcadas.  
El instalador automáticamente:

- instala Nmap
- añade Nmap al PATH
- instala WinPcap/Npcap (necesario para escaneos SYN)

### 3. Comprobar instalación

En PowerShell o CMD:

```cmd
nmap --version
```

Si responde, ya está instalado.

# Uso básico de Nmap

### Comando mínimo:

```bash
nmap [IP]
```

Esto escanea los **1.000 puertos más comunes**.

# Escanear puertos

## Selección de puertos – `-p`

### Un solo puerto

```bash
nmap -p22 [IP]
```

### Lista separada por comas

```bash
nmap -p22,80,443 [IP]
```

### Rango completo

```bash
nmap -p1-65535 [IP]
```

### Todos los puertos (forma abreviada)

```bash
nmap -p-
```

Esto equivale a escanear del 1 al 65535.

## Puertos más comunes – `--top-ports N`

```bash
nmap --top-ports 500 [IP]
```

Escanea los 500 puertos más utilizados según estadísticas globales.

> Útil cuando quieres un escaneo rápido pero más profundo que el escaneo por defecto.

## Mostrar solo puertos abiertos – `--open`

```bash
nmap --open [IP]
```

Nmap detecta puertos:

- **open** (abiertos)
- **closed** (cerrados)
- **filtered** (filtrados por firewall)
- **filtered** (indeterminado)

Este parámetro hace que **solo se muestren los abiertos**, ideal para limpiar la salida.

## Verbosidad – `-v`

```bash
nmap -v [IP]
```

Muestra información adicional durante el escaneo:

- puertos encontrados en tiempo real
- nivel de progreso
- hosts detectados
- qué técnicas se están usando

Durante el escaneo puedes **pulsar ENTER** para ver el % de progreso hasta al final.

## No resolución DNS – `-n`

```bash
nmap -n [IP]
```

Por defecto, Nmap intenta convertir cada IP en un nombre de dominio (DNS).  
Esto:

- ralentiza el escaneo
- genera mucho ruido en la red (consultas DNS)

`-n` evita esto → **más rápido y más sigiloso**.

## Velocidad y sigilo – `-T0` a `-T5`

Este parámetro controla la “temporalización”.

|Nivel|Nombre|Velocidad|Sigilo|Uso típico|
|---|---|---|---|---|
|T0|paranoid|extremadamente lento|máximo|evadir IDS|
|T1|sneaky|muy lento|alto|sigilo|
|T2|polite|lento|medio|redes frágiles|
|T3|normal|estándar|normal|por defecto|
|T4|aggressive|rápido|bajo|pruebas comunes|
|T5|insane|máximo|muy bajo|escaneos rápidos|

#### Ejemplo:

```bash
nmap -p- -T4 192.168.1.1
```

# Tipos de escaneo TCP

Aquí viene la parte más técnica.

## `-sS` – SYN Scan

Es el **mejor escaneo TCP**:

- rápido
- preciso
- silencioso (half-open)

### Funcionamiento:

```
Envío:   SYN
Respuesta:  
  SYN/ACK → Puerto abierto  
  RST     → Puerto cerrado
```

Nmap **no completa la conexión** (no envía ACK final), lo que reduce detección.

### Comando:

```bash
nmap -sS [IP]
```

## `-sT` – TCP Connect Scan

Se usa cuando **no tienes privilegios root** o el SO no permite SYN crudo (Windows).

HACE CONEXIONES COMPLETAS:

```
SYN → SYN/ACK → ACK → (cierra)
```

### Esto lo hace:

- más ruidoso
- más detectable
- más lento

### Comando:

```bash
nmap -sT [IP]
```

# Ver tráfico de Nmap: tcpdump y Wireshark 

## `tcpdump`

Herramienta de consola para **capturar paquetes**.  
Funciona a muy bajo nivel y permite ver:

- SYN / SYN-ACK / ACK
- paquetes ICMP
- tráfico ARP
- etc.

#### Ejemplo:

```bash
tcpdump -i eth0 -w captura.cap -v
```

### Explicación:

- `-i eth0` → interfaz a escuchar
- `-w captura.cap` → guarda en un archivo
- `-v` → modo verbose

## Wireshark

Visor gráfico de capturas.  
Permite ver:

- colores, gráficos
- estadísticas
- reconstrucción de flujos TCP

Para abrir la captura:

```bash
wireshark captura.cap &>/dev/null & disown
```

Y filtrar por un puerto:

```
tcp.port == 22
```

Esto permite comprobar exactamente qué paquetes envía Nmap.

# `-Pn` – Desactivar descubrimiento de host

Antes de un escaneo, Nmap intenta saber si el host está encendido mediante:

- ICMP Echo (ping)
- ARP (en redes locales)
- TCP en puertos conocidos
- otros métodos

Si el host no responde → Nmap NO escanea.

`-Pn` desactiva esto:

```bash
nmap -Pn [IP]
```

Nmap **asume que está vivo** y continúa el escaneo.

### Útil cuando:

- el firewall bloquea ICMP
- haces pentesting contra servidores protegidos
- necesitas escanear sin que detecten pings

---

# Escaneo UDP – `-sU`

UDP no tiene handshake, así que Nmap lo hace mediante:

- paquetes UDP
- respuestas ICMP “port unreachable”

El escaneo es:

- lento
- poco fiable
- fácil que dé “open|filtered”

### Comando:

```bash
nmap -sU [IP]
```

No recomendado usar `-p-`:

```bash
nmap -sU -p- [IP]   # Puede tardar horas
```

Mejor escanear solo puertos comunes:

```bash
nmap -sU --top-ports 50 [IP]
```

---

# `-sV` – Detectar versiones de servicios

Muy útil para encontrar vulnerabilidades específicas.

```bash
nmap -sV -p22,80 [IP]
```

Devuelve algo como:

- OpenSSH 8.2p1
- Apache 2.4.29
- vsftpd 3.0.3

Esto se puede correlacionar directamente con CVEs.

---

# Interpretación de la salida

## Estados:

| STATE      | Significado                              |
| ---------- | ---------------------------------------- |
| open       | Acepta conexiones                        |
| closed     | Puerto accesible pero no hay servicio    |
| filtered   | Un firewall bloquea el acceso            |
| unfiltered | Responde pero no se sabe si está abierto |

## SERVICE:

Nmap estima qué servicio corresponde al puerto.

Es orientativo, pero con `-sV` se hace preciso.

# Ver dispositivos activos en la red

Para ver dispositivos activos en la red anteriormente vimos `arp-scan`. Un método muy fiable en redes locales, ya explicado antes. Pero `nmap` tiene su propio método.

## Nmap Ping Sweep – `-sn`

Escaneo para ver qué hosts están encendidos:

```bash
nmap -sn 192.168.1.0/24
```

Filtrar solo IPs:

```bash
nmap -sn 192.168.1.0/24 | grep -oP '\d{1,3}(\.\d{1,3}){3}'
```

Ordenar:

```bash
nmap -sn 192.168.1.0/24 | sort -n
```

# Detección de sistema operativo – `-O`

Nmap puede intentar adivinar el SO mediante:

- tamaños de ventana TCP
- TTL
- respuestas ICMP
- fingerprinting activo

### Comando:

```bash
nmap -O [IP]
```

#### Pero:

- es agresivo
- es fácil que el firewall lo bloquee
- no muy preciso

Más adelante veremos técnicas mejores.

---

# Ejemplo final completo

```bash
nmap -p- -sS -T3 --open -sV -n -Pn 192.168.1.1
```

Incluye:

- escaneo completo
- rapidez media
- puertos abiertos
- versiones
- sin DNS
- sin ping previo
