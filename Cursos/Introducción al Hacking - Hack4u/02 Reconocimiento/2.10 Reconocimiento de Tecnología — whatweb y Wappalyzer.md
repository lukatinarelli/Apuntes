# 📚 Explicación teórica: Tecnología = Vector de Ataque

La **identificación de las tecnologías** es un paso crítico en el reconocimiento. Cuando hablamos de tecnologías, incluimos:

* **Lenguajes:** HTML, CSS, JavaScript.
* **Servidores Web:** Apache, Nginx, Tengine.
* **Librerías/Frameworks:** jQuery, React, Vue.js.
* **Sistemas de Gestión de Contenido (CMS):** WordPress, Joomla, Drupal.

Para el atacante, esta información vale oro: en base a la tecnología y su versión específica, se puede determinar qué vulnerabilidades conocidas son aplicables (ej. usar `WPScan` si se detecta WordPress).

---

# 🛠️ Herramientas de Identificación

## 1. Whatweb (Consola)

`Whatweb` es una herramienta de línea de comandos que escanea una URL y devuelve la mayor cantidad de información posible sobre las tecnologías que la componen, incluyendo versiones, servidores y fugas de información.

### Instalación:

```bash
sudo apt install whatweb -y
````

### Ejemplo de uso:

```Bash
❯ whatweb [www.miwifi.com](https://www.miwifi.com)
[http://www.miwifi.com](http://www.miwifi.com) [200 OK] Country[UNITED STATES][US], Email[...], Frame, HTML5, HTTPServer[Tengine], IP[157.185.129.134], JQuery[1.5.1], Script, Tengine-Web-Server, Title[MiWiFi – 小米路由器官网], UncommonHeaders[x-via,x-ws-request-id]
```

#### Análisis de la Salida:

| **Componente**          | **Explicación**                                                                                                                                       |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[200 OK]**            | Código de estado HTTP; la página respondió correctamente.                                                                                             |
| **Country[...]**        | País donde está alojado el servidor web.                                                                                                              |
| **Email[...]**          | Intenta reportar correos electrónicos detectados. (A menudo, como en el ejemplo, puede ser un falso positivo si son nombres de archivos de imágenes). |
| **HTTPServer[Tengine]** | **Servidor Web** utilizado. En este caso, Tengine[¹]:<br>                                                                                             |
| **IP[...]**             | Dirección IP del servidor o, más a menudo, de un balanceador de carga o WAF (Web Application Firewall) si lo hay.                                     |
| **JQuery[1.5.1]**       | Librería JavaScript **con su versión exacta**.                                                                                                        |

## 2. Detección de Vulnerabilidades por versión

El hallazgo más crítico de `whatweb` es la versión de la librería (ej. `JQuery[1.5.1]`).

**Procedimiento:** Al obtener una versión antigua o específica, buscamos activamente vulnerabilidades conocidas (_CVEs_) asociadas a ella:

1. **Buscar CVEs:** Usar bases de datos de vulnerabilidades como **Snyk** o **CVE Mitre**.
2. **Ejemplo:** La versión `JQuery 1.5.1` está obsoleta y, al buscarla en Snyk, encontramos múltiples vulnerabilidades conocidas (ej. XSS o _Prototype Pollution_).

🔗 **Snyk (Buscador de vulnerabilidades):** https://security.snyk.io/

🔗 **Ejemplo Vulnerabilidad:** jquery 1.5.1 vulnerability

## 3. Extensiones y Servicios Web

Existen alternativas gráficas para la detección:

- **Wappalyzer:** Extensión de navegador que analiza la página al vuelo y muestra las tecnologías detectadas en un icono (muy rápido).
- **BuiltWith:** Utilidad web que proporciona un informe muy detallado de todas las tecnologías, _analytics_, _widgets_ y _hosting_ de un sitio web.

---

# 📝 Notas importantes

> [!TIP]
> **Fugas de Información:** Whatweb a veces reporta fugas de información (*Information Leakage*), como direcciones IP privadas en cabeceras o comentarios, lo que puede ser un vector de ataque directo.

> [!NOTE]
> **CMS Específicos:** Si se detecta un CMS, cambie inmediatamente la herramienta de reconocimiento (ej. si es WordPress, use WPScan para un escaneo especializado de vulnerabilidades en plugins y temas).
