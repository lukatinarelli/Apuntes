# 🐧 Identificación de OS mediante TTL (Time To Live)


El **TTL (Time To Live)** es un valor numérico en el encabezado de los paquetes IP que indica cuántos "saltos" (enrutadores) puede dar un paquete antes de ser descartado. Su función principal es evitar que los paquetes circulen infinitamente por la red.

Sin embargo, para un atacante, el TTL tiene un uso secundario vital: **cada sistema operativo tiene un valor TTL predeterminado diferente** al generar un paquete. Esto nos permite identificar si el objetivo es Linux o Windows de forma extremadamente rápida y silenciosa.

## 📊 Valores Estándar de Referencia

|**Sistema Operativo**|**TTL Predeterminado**|**Rango Típico**|
|---|---|---|
|**Linux / Unix**|**64**|0 - 64|
|**Windows**|**128**|65 - 128|
|**Solaris / AIX**|**255**|129 - 255|

> [!NOTE]
> **El factor de los saltos:** Si haces ping a una máquina y recibes un ttl=63, lo más probable es que sea un Linux (TTL original 64) que ha pasado por un enrutador en el camino, restando 1 al valor original.

---

# 🛠️ Técnica: Ping vs Nmap

Tradicionalmente, usamos `nmap -O` para identificar el sistema operativo, pero este método:

1. Es **muy ruidoso** (envía muchos paquetes malformados para ver cómo responde el stack TCP/IP).
2. Es lento.
3. A menudo es bloqueado por firewalls.

Un simple **ping** es mucho más discreto y suele estar permitido en la mayoría de redes.


```Bash
# Ejemplo de respuesta en Linux
❯ ping -c 1 10.10.10.188
64 bytes from 10.10.10.188: icmp_seq=1 ttl=64 time=45.2 ms
```

---

# 🐍 Automatización: Script `whichSystem.py`

Para agilizar este proceso, utilizamos un script en Python que automatiza el envío del paquete ICMP, extrae el TTL mediante expresiones regulares y determina el sistema operativo basándose en los rangos.

## 🔍 Análisis de funciones clave:

- `get_ttl(ip_address)`: Utiliza la librería `subprocess` para lanzar un ping de un solo paquete (`-c 1`) y extrae el valor numérico del TTL usando **Regex** (`re.findall`).

- `get_os(ttl)`: Implementa la lógica de decisión. Si el valor está entre 0 y 64, lo marca como Linux; si está entre 65 y 128, como Windows.

### 🚀 Cómo utilizarlo:

Puedes encontrar el script completo en la carpeta de recursos del sistema.

🔗 **[Ruta script](Recursos/Scripts/whichSystem.py)** 

**Ejemplo de ejecución:**


```Bash
❯ python3 whichSystem.py 10.245.11.194

10.245.11.194 (ttl -> 64): Linux
```

> [!TIP]
> Si quieres usarlo desde cualquier parte de tu terminal, recuerda moverlo a `/usr/local/bin` y darle permisos de ejecución:
> 
> `chmod +x whichSystem.py && sudo mv whichSystem.py /usr/local/bin/`

---

# ⚠️ Limitaciones

Este método no es 100% infalible. Los administradores pueden cambiar el valor del TTL en el registro de Windows o en los archivos de configuración de red de Linux (hardening) para engañar a los escáneres. Aun así, en el 90% de los entornos, es una técnica de reconocimiento inicial brillante.
