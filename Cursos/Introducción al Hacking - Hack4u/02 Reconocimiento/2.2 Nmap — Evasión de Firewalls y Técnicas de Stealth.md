# 📚 Explicación teórica: ¿Qué es un Firewall?

Un **Firewall (Cortafuegos)** es un sistema de seguridad de red diseñado para monitorizar y controlar el tráfico de red entrante y saliente, basándose en un conjunto predeterminado de reglas de seguridad. Actúa como una barrera entre una red interna de confianza y redes externas no confiables (como Internet).

En el contexto del escaneo, el Firewall es el principal obstáculo, ya que puede:

1.  **Bloquear puertos específicos** (filtrando el estado a *filtered*).
2.  **Limitar la tasa de paquetes** (detectando un escaneo por su alta velocidad).
3.  **Inspeccionar paquetes** (detectando patrones de escaneo como el *half-open* SYN Scan).

La **Evasión** y el **Stealth** (sigilo) son cruciales para un pentester. Consisten en manipular los paquetes de red para que se parezcan a tráfico legítimo o para confundir a los sistemas de detección, evitando que el escaneo sea clasificado como malicioso y bloqueado.

# 🛠️ Uso práctico: Manipulación de Paquetes

Estas técnicas se centran en modificar la estructura o el origen de los paquetes IP/TCP para burlar las reglas de filtrado o los umbrales de detección.

## 1. 📉 Control de la Tasa y Velocidad (`-T0` a `-T5`, `--min-rate`)

Los IDS/IPS a menudo tienen umbrales para detectar escaneos basados en el número de paquetes por segundo. Reducir la velocidad es la forma más sencilla de sigilo.

| Parámetro | Nivel de Stealth | Descripción |
| :--- | :--- | :--- |
| **-T0** (paranoid) | Máximo | Envía paquetes muy espaciados, ideal para evadir IDS/IPS básicos. |
| **-T1** (sneaky) | Alto | Ligeramente más rápido que T0, pero aún muy lento. |
| **--min-rate <num>** | Personalizado | Asegura que Nmap nunca baje de un número de paquetes por segundo (útil para no ser *demasiado* lento o forzar una velocidad constante). |

```bash
# Escaneo extremadamente lento para evadir detección por umbral
nmap -sS -T0 [TARGET]

# Asegura que la tasa mínima sea de 0.5 paquetes por segundo para lentitud controlada
nmap -sS --min-rate 0.5 [TARGET]
```

## 2. 🪓 Fragmentación de Paquetes (`-f` y `--mtu`)

Los Firewalls a menudo inspeccionan la cabecera completa del paquete para determinar su propósito. Fragmentar el paquete divide la cabecera en múltiples partes, dificultando que el Firewall lo reensamble y analice correctamente.

- **-f**: Fragmenta los paquetes en trozos de 8 bytes (o menos).
- **--mtu <valor\>**: Permite especificar manualmente el tamaño máximo de unidad de transmisión (MTU), que debe ser un múltiplo de 8.

```Bash
# Fragmentación doble (más fragmentos, más pequeño)
nmap -sS -f -f [TARGET]

# Fragmentación manual a un MTU de 16 bytes
nmap -sS --mtu 16 [TARGET]
```

> [!WARNING] 
> La fragmentación excesiva puede ser inestable y puede provocar que el _target_ descarte los paquetes fragmentados, resultando en un escaneo inexacto o fallido.

## 3. 🎣 Decoy Scan (Engaño) — `-D`

Esta técnica oculta tu IP real en medio de una lista de otras IPs (falsas o reales), haciendo que parezca que el escaneo proviene de múltiples fuentes.

```Bash
# Usa dos IPs aleatorias (RND:2) y una IP conocida como Decoy, además de tu IP real (ME)
nmap -sS -D RND:2,192.168.1.100,ME [TARGET]
```

- `RND:N`: Genera $N$ direcciones IP aleatorias.
- `IP1,IP2,...`: IPs específicas a usar como señuelo.
- `ME`: Marca dónde poner tu IP real en la secuencia.

> [!IMPORTANT]
> 
> Usa siempre -n (No resolución DNS) junto con -D para evitar que la resolución DNS de los decoys falsos delate tu verdadera IP.

## 4. 🚪 Puerto de Origen Falsificado — `--source-port` / `-g`

Muchos Firewalls asumen que las respuestas que vuelven a un puerto de origen bien conocido (como el **53/DNS** o **20/FTP data**) son tráfico legítimo. Al forzar el puerto de origen, se intenta evadir las reglas de filtrado de retorno.

```Bash
# Escanea usando el puerto 53 (DNS) como origen
nmap -sS --source-port 53 [TARGET]
```

## 5. 🗑️ Longitud de Datos Aleatoria — `--data-length`

Añadir datos basura al paquete puede desviar la atención de los IDS que solo inspeccionan la cabecera IP/TCP o que tienen reglas de detección basadas en longitudes de paquete específicas.

```Bash
# Añade 50 bytes de datos aleatorios al paquete
nmap -sS --data-length 50 [TARGET]
```

# 💻 Comandos Específicos Adicionales

## 🌀 El Escaneo Sigiloso Base (`-sS`)

El **SYN Scan (`-sS`)** es la técnica de sigilo fundamental, ya que realiza un **half-open scan** (no completa el _three-way handshake_ TCP), lo que lo hace menos propenso a ser registrado por los sistemas operativos del _target_ en comparación con el `-sT`.

## 🌐 Falsificación de MAC Address (`--spoof-mac`)

Útil solo en la misma red local (LAN). Permite suplantar la dirección MAC del adaptador de red para evitar ser rastreado a nivel de capa 2.

```Bash
# Suplanta la MAC usando una dirección específica
nmap -sS --spoof-mac 00:11:22:33:44:55 [TARGET]

# Suplanta la MAC usando un nombre de proveedor aleatorio (ej. Cisco, Dell)
nmap -sS --spoof-mac Cisco [TARGET]
```

# 🏁 Ejemplo de Escaneo de Evasión Combinado

Una prueba de concepto avanzada requiere combinar varias técnicas para maximizar el sigilo:

```Bash
# Escaneo de evasión: SYN Scan, muy lento, fragmentado, sin ping y con Decoy
nmap -sS -T1 -f --mtu 24 -Pn -D RND:3,ME --source-port 20 [TARGET]
```

#### Desglose:

- `-sS`: Escaneo SYN sigiloso.
- `-T1`: Temporalización lenta (_sneaky_).
- `-f --mtu 24`: Doble fragmentación.
- `-Pn`: Asume que el host está vivo (evita que el bloqueo de ICMP detenga el escaneo).
- `-D RND:3,ME`: Usa 3 IPs Decoy aleatorias.
- `--source-port 20`: Fuerza el puerto de origen a 20 (FTP Data).
