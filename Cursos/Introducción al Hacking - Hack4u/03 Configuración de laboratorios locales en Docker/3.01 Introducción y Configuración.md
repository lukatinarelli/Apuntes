# 🐳 Introducción y Configuración de Docker en Linux

Docker es una plataforma que permite **empaquetar** una aplicación y todo lo que necesita para funcionar (librerías, dependencias, configuración) dentro de una unidad llamada **Contenedor**.

Para un pentester, Docker es como tener un "laboratorio instantáneo". Si necesitas probar una vulnerabilidad en una versión específica de Apache de hace 5 años, no necesitas formatear una máquina; simplemente descargas la imagen y la corres en segundos.

---

# 🆚 Contenedores vs. Máquinas Virtuales (VMs)

| **Característica** | **Máquina Virtual (VMware/VirtualBox)** | **Contenedor (Docker)**                                |
| ------------------ | --------------------------------------- | ------------------------------------------------------ |
| **Arquitectura**   | Incluye un SO completo (Kernel propio). | Comparte el Kernel del SO Host.                        |
| **Peso**           | Gigabytes (Muy pesadas).                | Megabytes (Muy ligeras).                               |
| **Velocidad**      | Tarda minutos en arrancar.              | Arranca en milisegundos.                               |
| **Aislamiento**    | Aislamiento total (más seguro).         | Aislamiento a nivel de proceso (suficiente para labs). |

---

# 🚀 Ventajas para el Hacking Ético

1. **Sandboxing:** Si ejecutas un malware o un exploit experimental dentro de un contenedor, el daño está limitado al contenedor. Tu sistema host (Kali/Parrot) permanece limpio.
2. **Infraestructura Efímera:** ¿Terminaste la práctica? Borras el contenedor y no queda rastro de basura en tu disco.
3. **Despliegue de Laboratorios:** Puedes levantar una arquitectura compleja (Base de Datos + Web + Firewall) con un solo comando usando `docker-compose`.

---

# 🛠️ Instalación en Sistemas Linux

Aunque los comandos pueden variar ligeramente según la distribución, en sistemas basados en Debian (como Kali, Ubuntu o Parrot), el proceso es el siguiente:

## 1. Instalación del paquete


```Bash
# Actualizamos repositorios e instalamos el motor de docker
sudo apt update
sudo apt install docker.io -y
```

## 2. Gestión del Servicio (Daemon)

Docker corre como un proceso en segundo plano llamado **demonio**. Es necesario activarlo para poder trabajar.

```Bash
# Iniciar el servicio
sudo systemctl start docker

# Configurar para que inicie automáticamente al arrancar el PC
sudo systemctl enable docker

# Verificar el estado
sudo systemctl status docker
```

## 3. Configuración Post-Instalación (Vital) 💡

Por defecto, Docker solo puede ser ejecutado por el usuario `root`. Para no tener que escribir `sudo` en cada comando, añadimos nuestro usuario al grupo `docker`:

```Bash
# Añadir usuario actual al grupo docker
sudo usermod -aG docker $USER

# Aplicar cambios sin reiniciar (o simplemente cierra sesión y vuelve a entrar)
newgrp docker
```

---

# ✅ Verificación del Laboratorio

Para asegurarnos de que todo está correctamente instalado y que el demonio responde, ejecutamos:


```Bash
# Verificar versión
docker --version

# Ejecutar un contenedor de prueba oficial
docker run hello-world
```

Si ves un mensaje que dice _"Hello from Docker!"_, tu entorno está listo para empezar a desplegar máquinas vulnerables.
