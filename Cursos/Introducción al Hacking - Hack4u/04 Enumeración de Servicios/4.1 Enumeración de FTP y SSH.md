# 🧐 Introducción al Servicio FTP

El **File Transfer Protocol (FTP)** corre por defecto en el **puerto 21**. Es uno de los servicios más comunes en auditorías. El reconocimiento se centra en dos vectores principales:

1. **Detección de versiones** (para buscar exploits conocidos como el de `vsftpd 2.3.4`).
2. **Configuraciones inseguras** (acceso anónimo o credenciales débiles).

## 🛠️ Escenario 1: Autenticación y Fuerza Bruta

En este caso, el servidor requiere un usuario y contraseña válidos y tiene el acceso de invitados desactivado.

### 1. Despliegue del Laboratorio (Docker)

Usamos una contraseña del diccionario **Rockyou**[^1] para la prueba:

```Bash
# Buscamos una contraseña al azar en la línea 3123322 del diccionario
cat /usr/share/wordlists/rockyou.txt | awk 'NR==3123322'
# Resultado: topgunner7

# Lanzamos el contenedor
docker run -d \
	--env FTP_PASS=topgunner7 \
	--env FTP_USER=admin \
	--name my-ftp-server \
	-p 20-21:20-21 \
	-p 40000-40009:40000-40009 \
	garethflowers/ftp-server
```

### 2. Reconocimiento con `nmap`

Antes de atacar, verificamos la versión y los scripts básicos:

```Bash
nmap -sCV -p21 localhost
```

_Si no aparece información de "Anonymous login", significa que necesitamos credenciales._

### 3. Ataque de Fuerza Bruta con `hydra`[^2]

Si conocemos el usuario (ej. `admin`), podemos intentar dar con la contraseña:

```Bash
hydra -l admin -P /usr/share/wordlists/rockyou.txt ftp://localhost -t 15
```

- **`-l`**: Usuario específico (minúscula).
- **`-P`**: Diccionario de contraseñas (mayúscula).
- **`-t 15`**: 15 hilos en paralelo para ir más rápido.

## 🕵️ Escenario 2: Acceso Anónimo (Anonymous)

Muchos servidores permiten el acceso con el usuario `anonymous` y cualquier contraseña (o vacía). Esto es un fallo crítico si hay archivos sensibles expuestos.

### 1. Despliegue del Laboratorio (Docker)

```Bash
docker run -d -p 20-21:20-21 -p 65500-65515:65500-65515 -v /tmp:/var/ftp:ro metabrainz/docker-anon-ftp
```

### 2. Detección Automática

`nmap` tiene un script específico (`ftp-anon.nse`):

```Bash
nmap -p21 --script ftp-anon localhost
```

**Resultado esperado:**

>```
PORT   STATE SERVICE
21/tcp open  ftp
| ftp-anon: Anonymous FTP login allowed (FTP code 230)
> ```

### 3. Conexión manual

```Bash
ftp localhost
# Name: anonymous
# Password: (vacio, solo pulsar Enter)
ftp> ls
```
