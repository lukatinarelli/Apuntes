# 🐍 Historia y filosofía de Python
Python fue creado para ser un lenguaje **simple, legible y práctico**, orientado a que el programador pueda centrarse en resolver problemas sin complicaciones sintácticas.  

Es un lenguaje **interpretado**, lo que significa que el código no se transforma en un ejecutable, sino que lo ejecuta un **intérprete**.
### Qué hace el intérprete:
- **Ejecuta el código línea por línea**, facilitando la depuración y la experimentación.
- Ofrece un **modo interactivo (REPL)** para probar comandos al instante.
- Permite ejecutar **scripts completos** (`python3 archivo.py`).
- **Compila a bytecode** (`.pyc`) para mejorar el rendimiento.
- Ejecuta ese bytecode en la **Python Virtual Machine (PVM)**, que abstrae el sistema operativo y hace a Python **portable**.
### Ventajas del modelo interpretado:
- Aprendizaje rápido y curva suave.
- El mismo código funciona en diferentes sistemas.
- Posibilidad de extender funcionalidades con módulos en C/C++ para mejorar rendimiento.

# ⭐ Características y ventajas
### Características principales
- **Sintaxis simple y muy legible**, ideal para principiantes y para escribir código limpio.
- **Interpretado y multiplataforma**, funciona en Windows, Linux y macOS sin cambiar el código.
- **Tipado dinámico**, las variables cambian de tipo según el valor asignado.
- **Biblioteca estándar muy extensa**, con módulos para casi cualquier tarea.
- **Soporte para varios paradigmas**: imperativo, funcional y orientado a objetos.
### Ventajas
- **Alta productividad**, gracias a su simplicidad.
- **Comunidad enorme**, con miles de librerías y herramientas.
- **Aplicable a casi cualquier área**: automatización, web, IA, ciberseguridad, ciencia de datos, videojuegos, etc.
- **Buena integración** con otros lenguajes (C, C++, Rust, Java…).

# 🔄 Diferencias Python2/3, PIP

### Python 2 vs Python 3
- **print**:
    - Python 2 → `print "texto"`
    - Python 3 → `print("texto")`
- **División**:
    - Python 2 → división entera por defecto
    - Pon 3 → división real por defecto
- **Cadenas**:
    - Python 2 → ASCII
    - Python 3 → Unicode
- **Soporte**:
    - Python 2 está **descatalogado desde 2020**.
    - Python 3 es la única versión mantenida y la usada actualmente.
### PIP2 vs PIP3
- **pip2** instala paquetes para Python 2.
- **pip3** instala paquetes para Python 3 (el estándar).
- Es recomendable usar **entornos virtuales** para evitar conflictos de dependencias.
