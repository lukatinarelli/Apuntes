## 📜 Descripción del Proyecto

Este repositorio contiene **apuntes, resúmenes, ejemplos prácticos y documentación técnica** que voy creando durante mi estudio continuo en:

- **Ciberseguridad**
- **DevOps y automatización**
- **Sistemas y redes**
- **Programación ofensiva y defensiva**

> [!NOTE]
> Todo el contenido es **original** y está pensado para **estudio personal y educativo**. Incluye explicaciones detalladas, esquemas, notas prácticas y comandos listos para usar.

## 📘 Contenido de los Apuntes

Cada curso incluye:

- Explicaciones detalladas en **Markdown (.md)**
